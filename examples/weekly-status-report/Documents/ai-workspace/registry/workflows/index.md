# Workflows

- [Onboarding Checklist Drafting](/workflows/onboarding-checklist-drafting.md) — Drafts a kickoff checklist for each new program from its scope and team. A draft checklist the program manager adjusts.
- [Program Risk Register](/workflows/program-risk-register.md) — Consolidates every open risk from the tracker's comments into the monthly register for the steering group. A risk register in the steering group's format, with each risk's owner and status.
- [Stakeholder Meeting Prep](/workflows/stakeholder-meeting-prep.md) — Assembles the agenda, open decisions, and talking points for each stakeholder meeting from the team's recent activity. A prep brief the program manager skims and corrects.
- [Weekly Status Report](/workflows/weekly-status-report.md) — Drafts the Friday leadership status report from the team's project tracker (progress, blockers and next week's focus), ready for the program manager's review by 10am.
