# Design's simulated leaders

Scripts for `design-workspace/evals/evals.json`, in the shared format (`framework-evals/students/README.md`): who you are, what you know, how you answer, when to stop. Each is the owner of the workflow in the eval's fixture; the fixture's requirements hold everything about the work itself, so the scripts hold only the leader's choices. No script uses a framework or evaluation term.
