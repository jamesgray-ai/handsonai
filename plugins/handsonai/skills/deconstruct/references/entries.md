# Entries that need a question first

Read when an entry check finds one of these: requirements in an earlier format (state 1), several unfinished interviews or one for a workflow the leader didn't name, or an unfinished Analyze. Section names in italics are SKILL.md's.

## An earlier version

When the requirements are in an earlier format (`routing-rare.md`, *Earlier versions*), Deconstruct owns state 1: ask N-B44 first when the workflow is live or was built (`routing.md`; its [steps] for pausing a schedule are filled as `references/platform-facts.md` rule 2 says); move the requirements and every later file (plan, build record, results) into `history/earlier-version-YYYY-MM-DD/`; with a registry, remove the node's "Design plan" (or legacy "Design spec") and "Test results" links under `# Artifacts` where they're there, since their files have moved, and restamp `generated`; say so in one line (model wording, naming the files in plain words: "its old requirements and plan"), offering the earlier requirements as a starting document (after N-B44, only the offer); then begin as for a new workflow, drafting from the old file at N-D1 if offered, with nothing in it current until the leader confirms it. The node keeps its status.

## Unfinished interviews: another workflow named, or several

   - One, and the leader named another workflow: say "[Name] is partway through Deconstruct; to finish it, say 'run the deconstruct skill on [Name]. My files are in [location].'", then carry on for the one they named.
   - Several, with none named: **Ask:** "You have [N] workflows partway through Deconstruct: [Name 1] (next: Part [N]), [Name 2] (next: Part [N]). Which one do you want to continue?" For a light interview, "(next: [the thing, in plain words])". With exactly two: "You have 2 workflows partway through Deconstruct: [Name 1] (next: Part [N]) and [Name 2] (next: Part [N]). Which one do you want to continue?"

## An unfinished Analyze

**An unfinished Analyze:** `analyze-in-progress.md` in the framework folder; on print-to-save, which has no progress file, a pasted or attached Analyze report whose top holds a **Report status** block ("**Report status:** unfinished — list not confirmed"; Analyze removes the block at its final write, so a finished report has none). **Ask:** "Your last Analyze session stopped partway, so those workflows aren't in your backlog yet. Finish it first, or carry on here?" "Noted" means any candidate in that file or report. When there is none yet: **Ask:** "Your last Analyze session stopped partway. Finish it first, or carry on here?" On "finish", give Analyze's start phrase in N-F2's approved form for this platform, exactly, with the working folder as the location, and stop, with nothing after it: on the web, "Start Analyze in a new chat. Add your [storage service] to it, then say 'run the analyze skill. My files are in [location].'"; on Claude desktop with the files in a local folder, "Start Analyze in a new chat with your working folder selected: 'run the analyze skill. My files are in [location].'"; on Microsoft 365, "Start Analyze in a new Cowork chat with: 'run the analyze skill. My files are in OneDrive, in ai-workspace.'"; on Claude Code and Codex, "Start Analyze in a new session in this project and say 'run the analyze skill.'"; on print-to-save, "Start Analyze in a new chat with: 'run the analyze skill.' Then attach the latest zip I gave you, or paste or attach the files you saved." On "carry on", continue. Not asked when N-F9 has just listed the unfinished Analyze session in this chat and the leader picked a workflow.
