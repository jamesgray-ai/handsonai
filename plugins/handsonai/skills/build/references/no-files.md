# With no files

Read on a surface with neither files nor a writable drive (print-to-save), before the opening.

On a surface with neither files nor a writable drive (print-to-save), ask first, before the opening: "To start, paste or attach your Workflow Requirements, your approved plan[, your build record], and the practice inputs and context files saved with them." The latest zip from the last step counts as all of them: unpack it if you can (`references/saving.md` rule 5). Say once, in place of N-F3 (N-F6): "I can't save files here, so I'll give you the files to save as we go. Where I can, I'll give you one zip of your working folder at each save point; keep the latest and attach it when you start the next step." Give the record, and the built text of every task built since the last save, at the end of each part, at a pause, a stop and the close, and before each main skill on a long build; on resume, rebuild and check again any task the record shows as checked but not saved. The pause line: "Before you go, save the build record below. To pick up, paste it into a new chat with the other files you saved, and say 'run the build skill'." Lines that send the leader to Design add first: "Save the build record below, and paste it into Design with your plan." (N-B9, N-B29, N-B50) or, at the open-item stop, "Save the build record below so we can pick up later."
