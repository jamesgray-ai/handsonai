# Drafting client updates

1. Read the engagement tracker row for the client.
2. Read this week's call notes.
3. Draft the update in the house style: what we did, what we found, what's next, and one
   decision we need from the client.
4. Keep it under 250 words.

## Gotchas
- Never promise a delivery date the tracker doesn't show.
