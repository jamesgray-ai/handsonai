# Summarizing calls

As of March 2025, the firm's standard call summary has five sections: attendees, decisions,
open questions, next steps, and risks.

1. Read the call notes.
2. Fill in the five sections.
3. If the user asked for a client update, turn the summary into the weekly status email.
