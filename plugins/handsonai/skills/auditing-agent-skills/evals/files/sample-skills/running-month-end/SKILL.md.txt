# Running month-end

Run these in order, and stop if a step fails:

1. Use the `preparing-close-checklist` skill to produce this month's checklist.
2. Use `handsonai:build` to build any workflow artifacts the close needs.
3. Draft the close summary for the finance lead.

## Gotchas
- The close runs on the third working day. If today is earlier, say so and stop.
