# Platform facts: where to look, and the safe path

The framework doesn't record what a platform can do: the tools change too fast. These rules apply wherever this skill needs a fact about the leader's platform.

1. **Where to look.** `platform-docs.json` lists each platform's official pages by topic: skills, plugins, subagents, scheduled runs, connectors, projects and memory. Read this skill's own `references/platform-docs.json`, or else `registries/platform-docs.json` at the plugin root; never fetch it from the web. Find a platform by its name or aliases. When you need a current fact, read the linked page if you can fetch it. If you can't, or the page doesn't settle it, take the safe path below and tell the leader once which page to check.
2. **Never make up a menu path, a button or a setting's name.** Give one only when a page you read in this session shows it, or a line in this skill gives it word for word. Otherwise say in one line that you can't confirm the exact steps, say in plain words what to look for, let the leader find it their own way, and name the page.
3. **Not sure a feature exists, or works the way the workflow needs** (subagents, scheduled runs, a skill choosing its own model, switching a connection off for one chat, the platform stopping an action before it happens): take the safe path this skill writes for that case, and say so once. Never claim it works as well, or the same way.
4. **Behaviour still waiting on a maintainer's check.** Where this skill says a path applies "once release check [N] passes", that behaviour isn't confirmed in this release, and nothing you can read changes it: take the path that applies until then. Never read a status, a version range or a release number to decide it.
5. **Never assume the leader's plan or subscription.** A fact that differs by plan is said for the plans it applies to, by name, never as theirs.
6. **A source you can't reach** (a website, a document link, a connection the step drafts from): say so in one line, and ask the leader to paste the key text (an About page, a list of offerings) or answer from memory. Never propose changing the environment, network settings, permissions or credentials to reach it.
