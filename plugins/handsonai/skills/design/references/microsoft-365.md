# Planning for Microsoft 365

Read when the plan's platform is Microsoft 365 Copilot. Part of `plan-template.md`, section 2.

**Microsoft 365: two places to build.** Skills are made in Cowork; an agent is made by Agent Builder in Copilot's Chat tab, from a prompt Build writes that names this plan and the requirements by folder. So an agent's blueprint is complete in itself: its name, description, mission, rules and checkpoints (by ID), the context files it reads (by C ID) and the sources it reads (its Work content). **An Agent Builder agent only reads:** Agent Builder can't author actions that use outside services (low-code actions, connectors and workflows need Copilot Studio, which this framework doesn't build in), and email added as Knowledge is read-only. So a workflow that sends, posts, creates, changes or deletes anything (an Outlook draft included) is never planned as an Agent Builder agent: plan it as Cowork skills, whatever the mechanism rule says (the mechanism stays `Agent` where the rule says so, no Agent Builder agent is made, S1 is the Cowork skill that starts the work), and the Approach says why in one line. Check the Agent Builder pages in `platform-docs.json` before relying on what an agent can do. The agent's own instructions hold everything it needs, its Skills field says none, and no Cowork skill hands work to it: a workflow that needs both is planned as one agent, or as skills alone. The Deployment Plan says the agent is made in Agent Builder and any skills in Cowork; Data Readiness gives each context file's runtime place as the workflow's own folder in Cowork's folder (`Documents/Cowork/[workflow-slug]/`), for skills (read by path) and agents (as Knowledge) alike. **A scheduled workflow on Microsoft 365:** Cowork's scheduled prompts run skills; an Agent Builder agent is never put on a schedule, so plan a scheduled workflow there as Cowork skills run by a Cowork scheduled prompt: the mechanism stays `Agent` when the mechanism rule says so, but no Agent Builder agent is made, S1 is the Cowork skill the scheduled prompt starts, and the Approach says why in one line. Reuse is offered only for a skills-only plan: an Agent Builder agent takes no Cowork skill.
