
# Where the files are

Part of the routing rule (`routing.md`), kept apart so a chat on Claude Code or Codex doesn't load it: there the workspace is the working folder and a start phrase carries no location. Read this on every other platform (Claude or ChatGPT on the web, Claude desktop, Microsoft 365), before anything is read, saved or asked, and whenever this chat can't find or read the framework files.

## What [location] is

For a phrase about one workflow, the location is the workflow's folder: on the web, the storage service by its own name and the folder ("Google Drive, in ai-workspace/framework/[workflow-slug]", "Dropbox, in ai-workspace/framework/[workflow-slug]", with the working folder's own name when the leader chose another; on Microsoft 365, "OneDrive, in ai-workspace/framework/[workflow-slug]"); on Claude desktop, the working folder by its own name ("ai-workspace/framework/[workflow-slug]"); on Claude Code and Codex, none (below). Before the workflow has a folder (and for Analyze), the location is the working folder ("Google Drive, in ai-workspace"; "OneDrive, in ai-workspace"; "ai-workspace"; none on Claude Code and Codex). A start phrase for a workflow built on another platform, to be said there (N-T15), takes that platform's location, in that platform's form above: for a workflow built for ChatGPT, "Google Drive, in ai-workspace/framework/[workflow-slug]", even when this chat reads a local folder.

## At entry: a drive to save to, and files this chat can read

**On Claude or ChatGPT on the web, in any tab or mode, ChatGPT's Work tab included (never Claude desktop, Microsoft 365 Cowork, Claude Code or Codex: any chat not working in a folder on the leader's computer counts as the web, and a sandbox or workspace the AI runs in online is not the leader's computer, and a folder the app made for this chat alone, named by date or after the chat, is never the working folder), before anything else,** when no connection in this chat can create files, or you can't tell: N-F16, "I can't see a drive I can save to in this chat. Add your cloud drive to this chat from the prompt box (or connect it first, if you haven't), with saving allowed, then say 'done'. Your work is saved as you go, so it needs a place: a drive such as Google Drive or OneDrive, a folder on your computer, or GitHub." On "done", look again (N-F16 again if there's still none); nothing is saved or asked until a place that can save is added. Then take the location from the start phrase, or find it (above). The opening confirms it in one line (N-F3). When this chat can't read the files the step needs, ask for them before anything else (N-F13). On Microsoft 365, only when Cowork can't find or read the framework files at the location (an admin may limit its OneDrive access): "I can't see your framework files yet. Attach your working folder in OneDrive to this chat, then say 'done'." Nothing is read, saved or asked until the files can be read; if they still can't be once the leader says "done", say so in one line, say that their Microsoft 365 admin can let Cowork read their OneDrive, give this step's start phrase with the location to say once that's done, and stop. On Claude desktop, when no folder is selected in this chat: "I can't see your framework files yet. Select your working folder in the prompt window, then say 'done'."

In short: On Microsoft 365, read the files from the location with nothing attached; only when Cowork can't find or read them does N-F13's Microsoft 365 form come first. On Claude desktop, a chat with no folder selected gets N-F13's desktop form first.

## Sending the leader to a new chat (N-F2)

On the web, a line that sends the leader to a new chat also has them add their drive to it, in N-F2's form: "Start [step] in a new chat. Add your [storage service] to it, then say '[start phrase]. My files are in [location].'" On Microsoft 365 the line says to open a new Cowork chat, and only names the folder, as on the web; on Claude desktop, with the files in a local folder, it says to select the working folder in the new chat. The forms, with the step's name and its start phrase filled in: Claude desktop with a local folder: "Start [step] in a new chat with your working folder selected: '[start phrase]. My files are in [location].'" Microsoft 365: "Start [step] in a new Cowork chat with: '[start phrase]. My files are in OneDrive, in ai-workspace/framework/[workflow-slug].'"

## The save promise's platform clause (N-F3)

On the web and in Microsoft 365 Cowork: "When [platform] asks to save to your drive here, choose Always allow for this chat; I'll only read and save inside your working folder."

## Picking up (N-F10)

On Claude desktop with the files in a local folder: "To pick up, open a new chat with your working folder selected and say '[start phrase]. My files are in [location].'" On Microsoft 365: "To pick up, open a new Cowork chat and say '[start phrase]. My files are in [location].'"
