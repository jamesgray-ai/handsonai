
# Lines every step says

Lines that are the same in every framework step and are said only at one moment. Read the section whose moment has come; nothing here is said at any other time.

## The dashboard wasn't refreshed (N-F20)

When it fails, say N-F20, exactly, as one line before the close: "Your dashboard wasn't refreshed this time, because something in your registry needs fixing first. To fix it, say 'update my registry. My files are in [location].'" [location] is the working folder, as a start phrase names it ("OneDrive, in ai-workspace" on Microsoft 365).

## The Git offer

**The Git offer,** only when the workflow folder is in a Git repository (with a shell, `git rev-parse --show-toplevel` returns the workspace; never on the web or in a drive), once, after the close. In a cloud session: no offer; commit, push and N-F18, as `references/routing-rare.md` says. Elsewhere: **Ask:** "Your folder keeps a history of its changes (it's a Git repository). Want me to save this point in that history, so you can come back to it later? It stays on your computer — nothing is shared." On a yes, stage only the framework's own paths, by name (`framework/[slug]/`, and `registry/` where it's in the repository), never `git add -A`, `-a` or `.`, a practice folder (`practice*/`), `.claude/settings.local.json`, secrets (an `.env` or key file) or the leader's other work; commit locally; never push. Either way, end with the start phrase again.
