# Saving through a connection

This applies wherever the working folder is reached through a connection (whatever storage service is connected in this chat) and not through files you write directly (Claude Code, Codex, a folder selected on Claude desktop). Name the service by its own name in every location ("Dropbox, in ai-workspace").

1. **After you save, read the file back.** If your change is there, carry on saving the same way.
2. **If your change isn't there,** save it as a new file instead: the create-only path, where the connection can move and rename files (the current file moved into `history/` first). Where it can't move them either, give the leader the file to save (print-to-save, with N-F6 once). Say in one line, in your own words, that the save didn't take and how you'll save from now on, and keep to that way for the rest of the chat.
3. **Never claim a save you didn't confirm.** Never create a file only to test saving, and never delete one.
