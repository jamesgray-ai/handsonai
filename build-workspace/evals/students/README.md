# Build's simulated leaders

Scripts for `build-workspace/evals/evals.json`, in the shared format (`framework-evals/students/README.md`): who you are, what you know, how you answer, when to stop. Each is the owner of Client Follow-Up in the eval's fixture; the fixture's requirements and plan hold everything about the work, so the scripts hold only the leader's choices and what only the leader can see (their screen, their accounts, what they set up before). No script uses a framework or evaluation term.
