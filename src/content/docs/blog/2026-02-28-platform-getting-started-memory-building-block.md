## Platform Getting Started Checklists

Each platform — [Claude](../../platforms/claude/getting-started/), [OpenAI](../../platforms/openai/getting-started/), [Gemini](../../platforms/google-gemini/getting-started/), and [M365 Copilot](../../platforms/m365-copilot/getting-started/) — now has its own Getting Started page. These walk you through account setup, app installation, personalization, memory, and connections (MCP, extensions, or connected apps) in one place. Platform setup content that previously lived in the Builder Tools Setup section has been moved here, so each platform tells its own complete story.

## Memory: The 10th Agentic Building Block

[Memory](../../agentic-building-blocks/memory/) is now a standalone building block — accumulated knowledge from past interactions (preferences, decisions, patterns) that makes AI persistent and personalized. It's distinct from Context (which you provide); Memory is what the system accumulates over time. The [Building Blocks overview](../../agentic-building-blocks/) and framework tables have been updated to reflect the new count.

## Product & Engineering Reorganization

The [Product & Engineering](../../product-engineering/) section has been reorganized with clearer navigation and a new Evaluation page covering how to assess AI outputs and measure quality.
