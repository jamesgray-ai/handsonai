Plugin 9.3 adds one skill, `auditing-agent-skills`, and a new playbook guide, [Agent Skill Best Practices](/agentic-building-blocks/skills/skill-best-practices/).

<!-- more -->

## Why it matters

Skills go stale. A model is retired, a skill another skill depends on is renamed, a fact written into the instructions stops being true, two skills grow to cover the same job. Nothing breaks loudly; the skill just does the job a little worse each time it runs.

## What the audit checks

`auditing-agent-skills` checks a set of skills against the same checklist `applying-skill-best-practices` uses:

- retired model names and references to skills that were renamed or removed;
- weak descriptions, naming drift, and skills whose descriptions overlap;
- dated facts and missing test cases;
- skills your AI Registry doesn't record, if you keep one.

Each finding comes with a specific proposed fix. It never changes a skill until you approve, and it audits large sets in batches of about 20 so each batch gets a complete report.

## How to use it

Ask your AI to "audit my skills". On Claude Code and Codex it reads your skill folders directly; in Claude and the other chat platforms, attach the skills or their ZIP files. Where your platform can run tasks on a schedule, run it monthly.

`applying-skill-best-practices` now also hands whole-set audits to the new skill, and the AI Workflow Framework's `build` skill follows it whenever it creates a skill.

Install or update the plugin, or download [auditing-agent-skills.zip](https://github.com/jamesgray-ai/handsonai-plugins/releases/latest/download/auditing-agent-skills.zip).
